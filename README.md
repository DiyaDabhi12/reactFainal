# 🎓 Student Management System (StudentHub)

A modern, full-featured React application for managing student records, built with **React**, **Redux Toolkit**, **React Router**, and **Bootstrap**. It features user authentication, search/filter capabilities, class segregation, and full CRUD operations connected via a local mock backend (`json-server`).

---

## ✨ Features

- **🔐 Authentication & Demo Login:**
  - Secure login and account creation screens.
  - One-click **Demo credentials auto-fill** (`admin@gmail.com` / `admin123`) for quick testing.
- **📊 Student Dashboard & Analytics:**
  - Real-time stat cards displaying total students, total active classes, and filtered results count.
- **🔍 Advanced Search & Filtering:**
  - Instant live search by student name or roll number.
  - Filter students dynamically by individual classes (e.g., Class 10-A, 10-B, etc.).
  - Smart sorting options by Name or Roll Number.
- **🛠️ Complete CRUD Operations:**
  - Add new student records.
  - View detailed student information.
  - Edit and update existing student information.
  - Delete student records with confirmation prompts.
- **🎨 Modern Responsive UI:**
  - Styled with custom CSS and Bootstrap components for smooth responsiveness across all screen sizes.

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite), React Router v6, Redux Toolkit
- **UI Framework & Icons:** Bootstrap, Custom CSS
- **Backend / Mock DB:** JSON Server (`db.json`)
